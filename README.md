# RichChess — Telegram Mini App

یک بازی شطرنج واکنش‌گرا برای Telegram Mini Apps با دو حالت:
- دونفره روی یک دستگاه
- بازی مقابل هوش مصنوعی محلی (بدون نیاز به API یا سرور)

## نیازمندی‌ها
- Node.js نسخه 20 یا جدیدتر
- npm

## اجرای محلی
```bash
npm install
npm run dev
```
سپس آدرس محلی‌ای را که Vite نمایش می‌دهد باز کنید.

## ساخت نسخه انتشار
```bash
npm run build
```
خروجی آماده انتشار در پوشه `dist` قرار می‌گیرد.

## راه‌اندازی به‌عنوان Telegram Mini App
1. پروژه را روی یک هاست دارای HTTPS منتشر کنید.
2. در گفت‌وگو با `@BotFather` یک بات بسازید.
3. از منوی بات، Mini App / Main App را تنظیم کنید و URL نسخه HTTPS را بدهید.
4. بات را به کاربر معرفی کنید؛ با باز کردن Mini App، رابط تلگرام به‌صورت خودکار شناسایی می‌شود.

در حال حاضر بازی برای حالت‌های محلی و مقابل AI کامل است. احراز هویت امن تلگرام، ذخیره ابری و بازی آنلاین بین دو دستگاه به بک‌اند نیاز دارند و عمداً در این نسخه ادعای پیاده‌سازی نشده‌اند.

## نکات فنی
- `chess.js` تمام قوانین قانونی شطرنج، از جمله قلعه، آن‌پاسان و ارتقای پیاده را مدیریت می‌کند.
- موتور AI یک minimax سبک با alpha-beta pruning است و در مرورگر اجرا می‌شود.
- اگر برنامه خارج از تلگرام اجرا شود، به‌صورت وب‌اپ مستقل کار می‌کند.
